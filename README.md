# Project5

Godot 4 project using the **Compatibility** renderer (GL Compatibility).

## Open the project

1. Clone this repository.
2. In Godot 4, select **Import** and choose `project.godot`.
3. Open the project. The renderer is configured as **Compatibility**.
4. Press **F6** to run `scenes/main.tscn`, or **F5** to run the project.

The main scene is an empty starter scene. Generated Godot cache files and exported builds are excluded from version control.

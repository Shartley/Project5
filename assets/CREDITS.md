## Models

Original designs made for this game. Each model is generated by a script in `tools/blender/`, so it can be rebuilt or changed:

| Model | Script |
| --- | --- |
| `models/enemies/goblin/goblin.glb` | `tools/blender/goblin.py` |
| `models/enemies/kobold/kobold.glb` | `tools/blender/kobold.py` (reuses the Goblin pipeline) |
| `models/weapons/dagger/dagger.glb` | `tools/blender/dagger.py` |
| `props/portal/portal_frame.glb` | `tools/blender/portal.py` (the swirling light is `props/portal/portal_swirl.gdshader`) |

Rebuild with Blender 5.x:

```bash
blender -b --factory-startup -P tools/blender/goblin.py -- <out_dir> full
```
